# 《跟着我的脸》需求文档

## 1. Overview

一款 20 秒的个性化左右反应挑战：玩家的头像向左或向右冲，写着 `{name} SAYS LEFT / RIGHT` 的巨大标牌会故意给出相同或相反方向；玩家必须跟头像走、忽略文字，在三次失误前连续作答。

### Interface brief

- 玩家：当前 AlterU 用户；平台外使用 `AlterU` 和指定的黑白塑封 U 默认头像。
- 核心交互：左半屏 / 右半屏二选一，Pointer 与键盘左右键。
- 情绪承诺：制造“我明明知道，却被自己的名字骗了”的可笑失误和立即重试冲动。
- 单一规则：`跟头像走，别信文字。`
- 目标尺寸：390×844 与 320×568 竖屏；不使用整页缩放。
- 信息预算：游戏中仅显示剩余时间、连击、一个文字标牌、一个头像和左右两个触区。

## 2. Visual Design

- 采用 1970 年代纸板电视游戏秀：奶油纸背景、番茄红左门、钴蓝右门、粗黑油墨、可见纸纤维与机械翻牌。
- 玩家头像是一枚有白边的圆形纸牌，在两个纸门之间横向冲刺；名字只出现在中央的大方向标牌上。
- 正确时头像撞开对应纸门；错误时头像撞上透明门被拍扁，标牌盖下 `YOU FOLLOWED THE SIGN` 判词。
- 禁止霓虹科技扫描、玻璃卡片、复杂教程、人物卡通化和 Emoji 功能图标。
- 完整视觉系统见 `doc/visual.md`。

## 3. Game Mechanics

- 开始页用真实头像与名字演示一组相反方向，玩家点击 `开始` 后进入 20 秒计时。
- 第 1–2 轮文字与头像方向一致；第 3 轮起，冲突概率从 45% 线性提高到 75%。
- 每轮头像方向为左或右；文字方向独立按冲突概率确定，不能出现没有明确方向的中间状态。
- 单轮反应窗从 1350 ms 线性缩短到 620 ms；超时算一次错误。
- 正确：同帧锁定输入，+100 基础分、+0–120 反应奖励、+`15 × 当前连击`；350 ms 后进入下一轮。
- 错误或超时：失误数 +1、连击归零；420 ms 后进入下一轮。第 3 次失误立即结算。
- 20 秒到时结算；结果显示分数、正确轮数、被标牌骗到的次数和最佳反应时间。
- 本地只保存最高分，不上传头像、用户名或逐轮行为。

### 状态模型

```text
loading → cover → playing → feedback → playing
   ↘ error → retry                  ↘ result → replay
```

## 4. Controls

- Pointer：左、右固定触区使用 `onPointerDown`，一次按下只判定一次；游戏区禁止文本选择和 iOS callout。
- Keyboard：ArrowLeft / A 选择左，ArrowRight / D 选择右，Enter 开始或重开，M 静音。
- 左右触区各占可用宽度 50%，高度至少 108 px；不是可滚动列表。
- 首次输入解锁 Web Audio；任何音频失败不阻塞判定。

## 5. Win / Lose Conditions

- 没有传统通关；20 秒未达到三次失误即完成完整挑战。
- 三次失误提前结束，结果明确区分“跟错方向”和“超时”。
- 12 个以上正确显示 `UNFOOLABLE`，7–11 个显示 `ALMOST IMMUNE`，0–6 个显示 `THE SIGN GOT YOU`。
- 再玩一次必须在 600 ms 内回到第一轮；身份加载失败时仍使用 AlterU 默认身份可玩。

## 6. Sound Effects

- 开始：330 / 440 / 660 Hz 方波三音，单音 55 ms，间隔 45 ms。
- 新轮翻牌：1100 Hz 三角波，25 ms，峰值 0.025。
- 正确撞门：170 Hz 低频纸板冲击 + 740 Hz 正弦短音，总长 130 ms。
- 错误拍扁：95 Hz 锯齿下滑至 55 Hz，180 ms；同时加入 40 ms 纸噪声。
- 连击 5/10：880 / 1100 Hz 或 880 / 1100 / 1320 Hz 上行音，间隔 55 ms。
- 结算：正确数 12+ 使用 520 / 780 / 1040 Hz；否则使用 420 / 630 Hz，单音 90 ms。
